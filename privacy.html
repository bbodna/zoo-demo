Privacy Policy

Being at the Zoo: A Wellness Game for Kids (working title)

Last updated: 24 October 2026

The short version

This game collects no personal information. It does not send anything anywhere. What you type and what you earn in the game stay on your own device.

What the game keeps on your device

  • Player names. When you set up a game you can type a name for each player. Names are optional. They are kept only on the device you are playing on, in the game's own storage, so they can be shown during the game and when you return to a saved game.
  • Progress and settings. One game in progress (whose turn it is, where the pawns are, which animals are in each Zoo Passport) and your settings (sound levels, read-aloud, less motion, picture quality) are kept in the same on-device storage.

Nothing in that storage leaves the device. The game has no code for sending information anywhere. The only thing it ever loads is its own files (the page, pictures, and sounds) from the place where it is installed or hosted.

How to remove it

  • The app: delete the app. Its storage is removed with it.
  • A web browser: clear the browser's site data for the page where you played. Starting a new game also replaces the saved game.

What the game does not do

  • No accounts, sign-in, or passwords.
  • No advertising.
  • No analytics, usage statistics, or crash reporting.
  • No chat, friends, leaderboards, sharing, or other social features.
  • No purchases of any kind. Tokens in the game are earned by playing and cannot be bought.
  • No links out of the game to web pages or other apps.
  • No camera, microphone, or location.
  • No motion sensors.

The optional "Read activities out loud" setting uses the voice already built into your device. The words are spoken on the device, not sent to a service.

The web demo

The free web demo is a single page of static files on a public web host (GitHub Pages at the time of writing). The page itself collects nothing. Like any website host, the host may keep its own standard server records under its own terms; the game adds nothing to them.

Children

The game is made for children to play with their families. Because it collects no personal information from anyone, it collects none from children.

Changes

If a future version ever changes any of the above (for example, by adding an optional feature that needs the internet), this page will be updated and the date at the top changed before that version is released.

Contact

Questions about this page can be left on the demo's public GitHub page: github.com/bbodna/zoo-demo (open an issue there). The owner may add an email address here later.
